# Parnuan Software Engineer — Assignment 1

ระบบรับข้อความการใช้เงิน แล้วแยกเป็นรายการให้ผู้ใช้ตรวจ แก้ไข ลบ และยืนยันก่อนบันทึก

## เทคโนโลยี

- **Next.js 16** และ App Router สำหรับโครงเว็บและการขยายไปทำ API ภายหลัง
- **Tailwind CSS 4** สำหรับทำหน้าใบเสร็จขาวดำและ responsive layout
- **TypeScript** สำหรับกำหนดรูปแบบข้อมูล
- **Vitest** สำหรับทดสอบกฎแยกข้อความ

## วิธีรัน

```bash
npm install
npm run dev
```

เปิด `http://localhost:3000`

ตรวจ build และ test:

```bash
npm run build
npm test
```

## ตอนนี้ทำอะไรได้แล้ว

- ใส่ข้อความ เช่น `ข้าวมันไก่ 50 น้ำเปล่า 7 แล้วก็ช้อปปิ้ง 500`
- แยกรายการเบื้องต้นด้วยกฎที่อ่านได้
- แก้รายละเอียด จำนวนเงิน หมวดหมู่ วันที่ และเวลาได้ก่อนยืนยัน
- ลบ ล้าง และยืนยันรายการ
- แสดงยอดรวมในรูปแบบใบเสร็จ

## ส่วนที่ 2: เวลาและข้อมูลที่ไม่ชัดเจน

parser รุ่นนี้เพิ่มการจัดการเวลาที่พบบ่อย:

- `15:00` อ่านเป็นเวลาแบบ 24 ชั่วโมง
- `บ่าย 3` อ่านเป็น `15:00`
- `เที่ยง` อ่านเป็น `12:00` และ `เที่ยงคืน` อ่านเป็น `00:00`
- `6 โมงเย็น` อ่านเป็น `18:00`
- `เมื่อวานตอน 5 โมงครึ่ง` แยกเป็นวันที่เมื่อวานและเวลา `17:30`
- `๕๐` แปลงเป็นจำนวนเงิน `50`
- `6 โมง` จะไม่เดาเช้าหรือเย็น แต่ใส่คำเตือนให้ผู้ใช้ตรวจเอง

ข้อมูลที่ parser ส่งออกจะผ่าน `transactionSchema` ก่อนแสดงบนหน้าเว็บ ทำให้รู้ทันทีถ้ารูปแบบข้อมูลไม่ครบหรือผิดชนิด

ถ้าไม่มีเวลา ระบบใช้เวลาที่รับข้อความเป็นค่าเริ่มต้นและใส่คำเตือนไว้ในรายการ เพื่อไม่ให้ผู้ใช้เข้าใจว่าเวลานั้นมาจากข้อความต้นฉบับ

## ส่วนที่ 3: ตรวจและแก้ข้อมูลก่อนยืนยัน

หลังแยกรายการ ระบบยังไม่บันทึกทันที ผู้ใช้กด `แก้ไข` เพื่อปรับข้อมูลที่เห็นได้จริงในรายการนั้น ได้แก่ รายละเอียด จำนวนเงิน หมวดหมู่ วันที่ และเวลา

ช่องเวลาให้กรอกเป็น `ชั่วโมง:นาที` เช่น `12:00` ระบบจะตรวจรูปแบบก่อนบันทึก ถ้าพิมพ์ไม่ครบจะแจ้งให้แก้ก่อน เพื่อไม่ให้ข้อมูลเสียเข้าไปในรายการ

### รูปแบบจำนวนเงิน

จำนวนเงินไม่จำเป็นต้องเขียนเหมือนกันทุกครั้ง ระบบรองรับรูปแบบหลัก ๆ เช่น `10`, `10บาท`, `10 บาท`, `฿10.50` และ `1,000 บาท` แล้วแปลงเป็นตัวเลขกลางก่อนตรวจสอบ
